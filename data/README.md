# Dataset

The project uses the ATLAS Higgs Boson Machine Learning Challenge 2014 dataset
(about 818k simulated events labelled signal or background). It is free on the
[CERN Open Data Portal](https://opendata.cern.ch/record/328) and is not stored
in the repo because the CSV is about 195 MB.

Run `python scripts/download_data.py` to download it into this folder.
